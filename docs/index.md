# gpmappy

`gpmappy` is a Python client for the OpenGWAS genotype-phenotype map API.

## Highlights

- Parity-first API design matching `gpmapr` functionality.
- Object-oriented `GpmapClient` plus module-level convenience wrappers.
- Strong validation and typed error model.
